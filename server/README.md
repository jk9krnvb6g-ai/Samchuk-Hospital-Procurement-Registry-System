# ⚙️ โฟลเดอร์ BACKEND (ส่วนหลังบ้านและ API)

โฟลเดอร์นี้คือ **Backend ทั้งหมดของระบบจัดซื้อจัดจ้าง** มีหน้าที่เชื่อมต่อฐานข้อมูล MySQL และส่งข้อมูลให้หน้าเว็บ

### 📁 ไฟล์ภายในโฟลเดอร์นี้:
1. **`index.js`** : ตัวเริ่มการทำงานของ Express Server (เปิดที่ Port 3002)
2. **`routes/procurement.js`** : เส้นทาง API ทั้งหมด (ดึงข้อมูล, บันทึก, ลบลงถังขยะ, กู้คืน, อนุมัติ, ออกเลขที่เอกสาร)
3. **`package.json`** : รายการ Dependencies ของ Backend (`express`, `mysql2`, `cors`, `body-parser`)
4. **`seed.js`** : สคริปต์สำหรับนำเข้าข้อมูลตั้งต้นหรือข้อมูลจำลองสำหรับทดสอบ
