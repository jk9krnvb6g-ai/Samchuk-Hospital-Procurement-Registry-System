# ⚙️ BACKEND (ระบบฝั่งหลังบ้าน API & Database)

โฟลเดอร์นี้รวบรวมโค้ดหลังบ้านทั้งหมด:
- `server/`: โฟลเดอร์ซอร์สโค้ดหลังบ้าน
  - `routes/procurement.js`: เส้นทาง API ทั้งหมด และระบบ Auto-Migration ฐานข้อมูล
  - `index.js`: ตัวเปิด Express Server (Port 3002)
  - `package.json`: รายการไลบรารี Dependencies ของ Backend
  - `seed.js`: สคริปต์สร้างข้อมูลจำลองสำหรับทดสอบระบบ
